# Webflow Custom GSAP Training

This repository is a collection of Webflow/GSAP experiments. The current examples are:

- [`Draggable & inertia/index.html`](./Draggable%20%26%20inertia/index.html): a bounded before/after comparison slider.
- [`Draggable & inertia/dragScript.js`](./Draggable%20%26%20inertia/dragScript.js): a two-axis drag experiment with inertia enabled.

To learn how to reason from the intended experience to the right animation model, mapping, and implementation order, read [Think in motion: a guide to designing GSAP interactions](./GSAP-PATTERNS.md). It analyzes the examples here and includes prompts for practicing the same design process on new ideas.
